    Escaping the mathjs Sandbox: From math.evaluate() to Remote Code Execution
    A bug bounty program led me into the internals of mathjs 11.8.2. Two property reads in the FunctionNode and SymbolNode compilers skip the library's own safe-property allow-list, so an evaluated constructor() expression reaches the JavaScript Function constructor and turns math.evaluate() into remote code execution. Root cause, the silent 11.9.1 fix, and a reproducible local proof of concept.
